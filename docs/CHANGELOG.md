# 变更记录

## 未发布

- 新增页面→壳通知桥：浏览器端插件经 `chrome.webview.postMessage` 上报，壳用托盘气球弹 Win11 系统样式 toast（绕开 WebView2 自绘通知的非原生样式，且不依赖页面通知权限）；浏览器环境仍走 Notification API
- 壳内放开页面通知权限：对本机 Harness 源的 Notification 请求自动授权（WebView2 默认静默拒绝，曾致浏览器端通知插件拿不到权限），其余权限仍默认拒绝；启动时自动复位旧版本遗留的通知权限拒绝记录（持久化的拒绝会短路权限请求事件，不复位则授权永远轮不到）
- 菜单新增「退出APP（保留服务）」：只关闭壳（窗口 + 托盘），后台 Harness 服务继续运行，下次启动自动接管；原「退出」仍为完全停服
- 顶栏余额新增 Kimi 额度显示：设置页切换来源，5h/7d 双窗口已用百分比
- 修复点余额菜单「刷新」时菜单收拢动画被瞬关打断；状态卡接入全局关闭钩子，点外部也播淡出动画
- 整体审查加固：额度来源热切换时丢弃迟到旧来源响应；手动刷新遇网络失败状态卡如实反馈（保留上次值）；Kimi/DeepSeek 数据解析兼容浮点与数值形态、重置时间兼容 Unix 时间戳、百分比钳位 0~100；设置页 Key 输入框路过焦点不再误清已保存 Key；应用退出时尾行日志不再丢失；修复重试/重启在页面内核未就绪时的报错天书；代理重试连接稳定性、npm 输出读取死锁兜底、全局鼠标钩子等十余处可靠性修复
- 启动页加入场动画：品牌区/进度卡片抛出回弹（1.2s 慢入场档）
- 进度条重做：像素点阵屏 + 彗尾光柱，步骤/下载真实进度驱动
- 页面外链改由系统浏览器打开（接管新开窗口请求）
- 最小化到托盘后挂起页面渲染，驻留不空转
- 关于/设置/诊断/进度窗统一支持 Esc 关闭
- 菜单支持键盘操作：Esc 关闭，↑↓ 选择
- 键盘焦点框可见，Tab 不再盲操
- 设置窗口超高时出滚动条（620px 上限）
- 关于窗口品牌字形换内嵌图标，免字体回退
- 低端渲染环境自动关闭菜单模糊动画，防掉帧
- 页面加载失败原因中文化，不再直显英文枚举
- 设置新增界面缩放（100/125/150%）
- 托盘悬停提示带服务状态（运行中/已断开）
- 菜单与余额状态卡加轻阴影，悬浮层次更强

## v1.4.0（2026-08-19）

- 设置新增「打开数据目录」，一键直达日志与数据存放位置
- 应用更新提示展示更新内容（GitHub Release 说明），长文本可滚动
- 设置新增「清理页面缓存」，下次启动时清理，不动登录态
- 修复高 DPI 下托盘菜单向上展开时动画方向判反
- WebView2 Runtime 缺失时给出专用引导（下载安装后点重试，免重启应用）
- 日志文件超 2MB 启动时自动截断，不再无限膨胀
- 启动时 Harness 与应用更新检查并行，互不等待
- 日志与状态回调改异步派发，大量输出时不再卡顿
- 主窗口代码按职责拆分六个文件，纯移动无行为变化
- 用户可见文案整体打磨，更简洁自然
